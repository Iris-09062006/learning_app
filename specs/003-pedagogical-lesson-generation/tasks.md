## Locked implementation budget

- Database migration tasks: **0**.
- Pedagogical model for Calls 1-5: **exactly `gemini-3.6-flash`**; endpoint/credentials may remain configurable, model identity may not.
- Normal successful Lesson: **3 provider calls and exactly 3 outbound HTTP requests** — synthesis+blueprint, all sections, independent review.
- Worst correctable Lesson: **5 provider calls and at most 5 outbound HTTP requests** — normal three plus one targeted correction and one independent re-review.
- Correction allowance: **maximum 1**; no loop and no sixth call.
- Transport behavior: **exactly 1 outbound request per stage invocation**; malformed output, provider error, timeout, or reported model substitution fails without retry, alternate-model routing, or fallback.
- Course concurrency: **maximum 3 Lesson pipelines/provider calls**, with stages sequential inside each Lesson.
- Provider timeout: **45 seconds per call**; Course scheduling deadline: **240 seconds**; server route envelope: **300 seconds**; existing browser Continue wait: **60 seconds plus persisted-state refresh**.
